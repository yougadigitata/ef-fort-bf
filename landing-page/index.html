❓ Questions fréquentes

Que faire si je ne me souviens plus de mon ancien mot de passe ?

Pas de panique ! Google ne demande pas forcément votre mot de passe actuel. Voici les alternatives :

  • Utilisez votre numéro de téléphone de récupération pour recevoir un code SMS
  • Utilisez votre adresse email de secours pour recevoir un lien de récupération
  • Si vous avez un appareil de confiance avec une session ouverte, Google peut vous identifier
  • Essayez de taper des anciens mots de passe que vous avez déjà utilisés — Google les accepte parfois
  • Consultez votre gestionnaire de mots de passe (Chrome, Bitwarden, 1Password, etc.)
Comment retrouver la date de création de mon compte ?

Google peut vous demander la date approximative de création de votre compte. Voici comment la retrouver :

  • Cherchez l'email de bienvenue Google dans votre ancienne boîte mail (objet : "Bienvenue sur Gmail")
  • Consultez vos anciens appareils — la date d'activation Google y est souvent enregistrée
  • Regardez vos réseaux sociaux liés à ce Google (Facebook, Instagram) pour trouver une date d'inscription cohérente
  • Essayez une plage large (ex: "début 2018") si vous n'êtes pas précis — Google accepte les approximations
Puis-je récupérer mon compte sans téléphone de récupération ?

Oui, c'est possible mais plus difficile. Google propose d'autres méthodes de vérification :

  • Email de secours : si vous en avez configuré un, c'est la méthode la plus facile
  • Appareil de confiance : un téléphone ou ordinateur où vous étiez déjà connecté peut servir à valider votre identité
  • Formulaire de vérification d'identité : Google propose un questionnaire approfondi (mots de passe précédents, contacts, date de création)
  • Application Google : si vous êtes connecté sur un autre appareil, vous pouvez approuver la connexion via une notification
Google a refusé ma demande de récupération, que faire ?

Un refus n'est pas définitif. Voici les étapes à suivre :

  • Attendez quelques jours et réessayez — les chances augmentent avec le temps et la cohérence des réponses
  • Changez d'appareil : essayez depuis un appareil différent (téléphone, PC, tablette) — Google considère l'historique de chaque appareil
  • Utilisez un réseau familier : connectez-vous depuis un WiFi que vous utilisez habituellement (maison, bureau)
  • Variez vos réponses : si vous n'étiez pas certain de certaines dates, essayez des variantes plausibles
  • Option premium : si tout échoue, notre conseiller peut vous accompagner dans une démarche plus approfondie
Mes données sont-elles en sécurité avec votre assistant ?

Absolument ! Notre assistant respecte strictement la confidentialité :

  • Aucun stockage : toutes vos réponses restent dans votre navigateur (JavaScript côté client uniquement)
  • Aucun mot de passe demandé : nous ne vous demandons jamais votre mot de passe actuel ou ancien
  • Aucune collecte de données sensibles : l'adresse Gmail saisie n'est pas transmise à nos serveurs
  • Conformité RGPD : notre outil est 100% conforme aux réglementations européennes sur les données
  • Liens officiels uniquement : nous vous redirigeons vers les pages officielles de Google pour toutes les actions
